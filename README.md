## Generare i PDF

I PDF in `assets/pdf` sono generati con Chrome headless a partire da `index.html` (IT) e `en.html` (EN).

```
npm install
npm run pdf
```

Serve Google Chrome installato. I PDF vanno rigenerati e committati a ogni modifica dei contenuti.
